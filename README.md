## Contenido

El archivo `Untitled0.ipynb` contiene un ejercicio de programación en Python para representar funciones cuadráticas usando `NumPy` y `Matplotlib`.

Se trabajan las funciones:

- `f(x) = -x² + 6x + 7`
- `g(x) = -x² + 6x + 10`

El notebook muestra sus gráficas, raíces, interceptos con el eje `y`, vértices y el eje de simetría de las parábolas.

### Elementos representados

Para la función `f(x)` se identifican:

- Raíces: `(-1, 0)` y `(7, 0)`
- Intercepto con el eje `y`: `(0, 7)`
- Vértice: `(3, 16)`
- Eje de simetría: `x = 3`

Para la función `g(x)` se representa además el vértice `(3, 19)`.
